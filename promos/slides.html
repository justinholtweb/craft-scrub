The preview

The preview
is the run

The same method, with one boolean deciding whether the result is written or thrown away.

  • Not a cheaper code path that can disagree
  • So it finds the place you forgot existed
  • The console previews by default — you ask for the write
$ php craft scrub/run/replace \
    --find="Acme Ltd" --replace="Acme Inc" --mode=word
31 matches in 12 places (12 candidates scanned in 0.09s)
  Acme Ltd annual report (Entry, Plugin Testing)
    Title
      … [-Acme Ltd-]{+Acme Inc+} annual report…
Dry run — nothing was changed. Pass --dry-run=0 to write.

Matching

Matches the
way you meant

Plain, whole words only, or a regular expression with capture groups.

  • You never escape delimiters
  • Case preservation works word by word
plain→form, platform, information — 8
whole word→form — 4
regex→2026-08-18 → 18/08/2026
keep caps→widget, Widget, WIDGET — one rule

“Acme Ltd” becomes “Acme Inc”, not “acme inc” — which is what word-by-word buys you.
